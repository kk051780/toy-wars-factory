## Windows Roblox Studio で確認すること
1. GitHub Actions の最新成功ランから `P0D-H1-RICH47-WAYPOINT-V4-6SKILL-SESSION-PRIVATE51-STUDIO-PLACE` をダウンロード。ZIPを展開し `P0D_H1_SKYV5_WAYPOINT_6SKILL_SESSION_PRIVATE.rbxlx` をStudioで開き、**Publishはしない**でください。
2. `Test → Play` で1人開始。赤青いずれかの自陣の道場6種を歩いて確認。追加4分野を修行すると、6系統試作パネルにXPとLvが増えることを確認してください。
3. 無操作で修行台に滞在するとXPが伸びます。フレンドが本当に同じStudioサーバーにいる場合のみ、V4側のサーバーによるフレンド確認値を反映。セッション外で貯めてくれる仕組みではありません。
4. 道場を離れて卵を奪い、天空城V5の坂へ登り、自陣へ納品。現在のサーバーの得点や進化表示、7秒の結果カードは以前と同じであることを確認します。魔獣／武器道場がおすすめされれば、**元47本版と同じ**20秒の実道場目印が出るか確認してください。
5. 2人試遊、再戦、Android相当の小画面UIで、V4パネルと元HUD、結果カード、道場目印が重ならないか評価してください。`[P0D_V4_BRIDGE]` と `[P0D_STUDIO_RESULT_ADVISOR]` のOutputも確認できます。
