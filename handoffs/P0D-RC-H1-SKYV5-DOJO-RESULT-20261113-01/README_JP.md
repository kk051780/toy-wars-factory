# P0D H1：戦闘→修行→再戦の7秒ガイド（Studio未公開・47 Luau試遊版）

## この版で遊べること
前回統合した**45本すべての原本ソースを変更せず**、試合終了時に小さな案内カードを7秒だけ自動表示します。ユーザーはすぐ再戦でき、右上の「×」で閉じることもできます。カードは非公開Roblox Studio以外では実行されず、新しいRemote／ゲーム権限はありません。

**今回の追加改善：** カードが「魔獣道場／武器道場へ」と提案した場合、ゲーム内の**実在する自陣道場（サーバー作成済みの実Part名・TrainingSkill・FreeTraining・StudioSessionOnly属性をすべて検査）**の上に目印を一時表示します。想像した座標を表示しません。結果カードは従来どおり7秒、道場目印は最大20秒で消えます。カードの「×」で即消去、次の試合がACTIVEになっても自動消去します。進化推奨・すべてLv5で再戦推奨・実道場Partが存在しない場合は目印を表示しません。Studio外では非実行、クライアントローカルのみです。

元のB42卵1/5争奪、V7無双敵、天空城V5地面接続4本、厳密な同一卵診断V4、赤青各2台のBEAST/WEAPON放置道場、1人練習時のラウンド固定、XP／進化／保存の既存コードを保持します。

戦闘後の表示例は「勝利！｜チーム得点2」「つぎは魔獣道場で放置修行！」です。この数字は**本人の卵納品数ではなくチームの実得点**。進化可のサーバー情報が出れば「つぎは進化をチェック！」を優先します。道場レベルは実装済みの魔獣・武器2つだけ。双方Lv5なら再戦を促します。

**表示しないもの**：個人の総撃破数・救助回数（現在のサーバースナップショットには累計がない）。孵化の実行可能性（単なる`hatchEnabled`は卵獲得の証拠ではないため）。6分野の育成（別機能で未採用）。課金やボタンで経験値を購入する操作。

## Windows Studioでの確認
1. GitHub Actions最新成功ランの `P0D-H1-SKYV5-DOJO-RESULT7-47-PRIVATE-STUDIO-PLACE` ZIPを取得し、`P0D_H1_SKYV5_DOJO_RESULT7_PRIVATE.rbxlx` をWindows Roblox Studioで新規に開いてください。**Publish禁止**。
2. 1人の`Test → Play`で開始し、道場でBEAST/WEAPONレベルを上げ、雑魚を倒して敵卵→天空城V5→自陣へ納品を試してください。右下の厳密な0/4→4/4はこれまでどおり維持します。
3. 試合終了時、画面上部に「勝敗／チーム得点／次の一手」の7秒カードが現れ、自動で消えることを確認します。**実際の道場への提案時だけ**、自陣の対応する道場の上に「次はここで修行！」という目印が表示されるかチェックします。カードは7秒、目印は最大20秒で消えます。×を押すと両方即時閉じます。`[P0D_STUDIO_RESULT_ADVISOR]` で始まるOutputログが出ます。
4. 途中で画面の切り替えがあっても、前ラウンドのカードが次の試合へ残らないことを確認します。進化可能なら進化、そうでなければ低レベルの魔獣／武器道場を案内することを確認します。
5. 2人試遊では、片方が退出した後にソロ練習へ切り替わらないこと、プレイヤー本人とチームの得点を混同しないことを確認します。Android/小画面ではカードと既存HUDの重なりを評価してください。
