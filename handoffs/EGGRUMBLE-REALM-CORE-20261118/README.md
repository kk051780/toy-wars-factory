# GQ8 REALM CORE34｜陸海空・海中を基本戦場へ（2026-11-18）

## 今回の実装
1. 航空機：全7職共通の出撃パッド、最大2機/世界。VehicleSeatの旋回/推進＋サーバ側3Dピッチ/ロール/高度制御。HP120、機銃9/0.20秒、爆弾46/8秒・3発。
2. 騎乗戦闘：既存LSSの船は艦砲30/2秒、海獣・飛行獣は火炎20/1.25秒、飛行艇は機銃。サーバが現在試合・操縦席・職業・生存・頻度を確認。
3. 海中：公共潜水/帰還、海底専用床と珊瑚、海中Leviathan最大3体（HP70）。水中波14/0.75秒。海中敵は近接6ダメージ/2秒。通常SwarmのKOやスコア管理を上書きしない。
4. 属性：Realm専用攻撃は潜水時の火属性x0.15、雷属性x1.35。**既存7職の全攻撃まで耐性を広げるには元Combatに一意の受理APIが必要で、まだ全域適用していない**。
5. 天候：晴れ・強風・雨・雷雨の各35秒循環。風/雷雨による航空速度低下、高高度機への雷被弾20ダメージ/7秒、2秒前のサーバ警告フラグ。
6. コンバット制約：Realmの新海中敵と飛行機、BR限定の既存LSS乗り物だけに新ダメージを加える。**TEAMの味方情報は従来Host側のみ**のため、TEAMでの乗り物PvPと既存の人間/城/卵の新ダメージは安全な受理インターフェースが出来るまで禁止。

## 操作
- 戦闘機：通常操縦桿/方向キーで旋回と推進、R/F=ピッチ上下、Q/E=ロール、G=機銃、B=爆撃。スマホは搭乗UIのボタン。
- 船=艦砲C、海獣/飛行獣=騎乗攻撃V、海中=水中波H。搭乗UIは現在の乗り物で自動切替。
- 操作イベントは入力指示だけ。ダメージ/HP/兵器クールダウン/移動はサーバ決定。

## 基礎採用と復元
compose_core34.py は現在正式RCの真正31本を抽出したプロジェクトを入力に、元31本の内容を一切変更せず、旧陸海空ソースからStudio限定ガードを**生成コピーに限って**外し、新ServerとClientを追加して34本の新しい基本構成を生成する。OFFは元31へ厳密復元。旧LSSの作業用ソース・現行rich51・既存Game/Combat/Swarm/Store/Scoreは変更ゼロ。

CIは現正式HEADの成功済み31本を再抽出し、真正Native34/31、Rojo34/31、source/class一致、逆方向OFF31を検証する。旧primary rich51はRC合格まで無変更。main/Publish/課金しない。
