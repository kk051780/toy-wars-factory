## Real game behavior
The V3 author source `EGGRUMBLE_SkillFX.luau` emits exactly seven named secondary role skill silhouettes. This client LocalScript identifies only those seven parts inside `EGGRUMBLE_LOBBY_CASTLE_MODES_PREVIEW` (TEAM/BR worlds). At normal FPS and no user reduced-effects preference, everything stays rendered. With two consecutive 1-second samples at <=34 FPS, or user attribute `EGGRUMBLE_ReducedEffects=true`, only secondary skill silhouettes >=125 studs from the camera become locally transparent. Two consecutive >=47 FPS samples restore them. Near-range 7-role abilities, `FX_*_FLASH`, `FX_*_RING`, ultimates, boss telegraphs, castle/egg, neutrals, pickups, hit marker, and lobby remain visible. This changes **render visibility only**, not hitbox, damage, server power, role cooldown, movement or economy. 144-part hard tracking limit, .35-second visibility checks, 1-second FPS buckets, old transparency restoration on script deletion and arena teardown. Both match modes share the same passive visual contract.
