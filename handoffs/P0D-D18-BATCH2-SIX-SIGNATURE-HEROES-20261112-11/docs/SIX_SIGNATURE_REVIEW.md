# 造形の差別化・遠景輪郭監査（ソースのみ）

6体とも同一抽象モデルの色替えではない。それぞれ姿勢・材質・中心の置き方を変え、3種類の名前付きシルエット要素を遠景LODで保持。

- **BE009** 3筋の彗星尾/胸の割れた五芒星/左右非対称角の欠け
- **SP018** 一箇所開いた音輪/右のきのこ灯/左の二重こだま玉
- **VE027** 左が大きい歯輪/真上を指す望遠鏡/前のない座席
- **WE036** 曲がる吹奏管/六角の氷章/ぶら下がる一個の氷鈴
- **ZO045** 二色割れ旗/曲がった高帽の羽/左右違う靴
- **TR054** 二重波紋/片側に高いしぶき/明るい方向矢印

**本試験はJSONのfar=trueと固有タグ3種を検証するだけ**で、実際の48pxレンダリングが子どもに判別できるかは未検証。Studioとモバイル実機で確認する。

3Dはローカル`WorldModel`のみ、戦場と接触・傷害・射程・ジャンプ・罠発動の権威は持たない。
