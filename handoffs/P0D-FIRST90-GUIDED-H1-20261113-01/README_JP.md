元になったゲーム：本物の進化/所持/XP/覚醒/5卵得点/旧1卵争奪/拘束/救出/8雑魚＋精鋭を備えた40-Luau単一Game、固定source `1b21bf8e5fc6afa5c74813d7f1037f877e1273ed`。今回 **41本目の純ルール `First90GuideRules.luau`** を追加、Server Game/Client HUD/既存Hordeのみを隔離コピーでパッチ。元の既存37/40ソースは同一。

## 実装した導線（本物のサーバーイベント）
- 開戦〜24秒：中立兵8体に範囲斬撃。「⚔ 中立兵をまとめて倒そう！」。実際のサーバーの `horde:hit` が1体以上に当たった場合だけHIT達成。クライアント側の偽HITで進まない。
- HIT成功または24秒経過：旧ルールなら敵陣の卵、5卵モードなら複数卵へ。既存 `Progression.recordEvent` で承認されたPickupがあればPICKUP達成。
- 運搬中は常に「自陣へ戻れ」。旧1卵と5卵の納品先を正しく区別。
- 卵納品が成功したら「魔獣召喚」を促す。正規 `RewardRules.requestScout`＋`spawnActualScout` 成功時だけSCOUT達成。
- 中立精鋭が1.5秒の予兆で赤い9-stud危険円を出したら、何を案内中でも「⚠赤い円の外へ！」を最優先。拘束中の脱出、近くの味方の救助も上位。
- 対象試合90秒で完全に案内を非表示。途中参加・進捗不足でも詰まらず、同一試合の強さ・得点・報酬を増やさない。次試合でのみ独立リセット。
- 攻撃型魔獣の実射程も修正。従来の空中モデルの座標`anchor`を`horde:hit`に渡すと、もともとの`SWEEP_MAX_VERTICAL=5`stud判定で地上の中立兵に届きにくい。**判定中心を実プレイヤーの`currentRoot.Position`に置く**。空中の3Dスカウト表現は維持、壁・高低差・射程を無視する当たり判定にはしない。
- 魔獣の能力と召喚許可時間の不一致も独立QAに応じて修正。元のサーバー発行`SCOUT_DURATION=5`秒は維持し、守護バリアは最大5秒・最大3/5回、攻撃魔獣はこの1回の召喚で実際に命中したら範囲攻撃を1回だけ発動。命中しなければ5秒の間に再試行、8秒の架空バリアや12秒待たないと2発目という誤説明はしない。新しいPvP威力、素材、XPは付与しない。
- シンプルな文字表示は一つの現行HUDの中央下寄り。広告/購入/強制操作/勝手なワープ/無料経験値の追加はゼロ。

## ユーザーが実際にチェックする90秒（目視のGO/NO_GO）
0–15秒：まず「どこに行く／何を押す」が分かる、攻撃で雑魚を払う爽快感、被弾前の予兆が理解できる。
15–40秒：卵を見つけられる・拾うボタンが押せる。相手との奪い合いが起きる。
40–70秒：運搬中に味方陣地へ戻れる、対人の戦いから離脱できる、拘束から救助できる。
70–90秒：召喚・成長の楽しさが見える。再戦したくなるか？ モバイルボタンが干渉しないか？
**5項目評価**：A戦闘爽快感 / B卵ルール初見理解 / C攻防の混沌と戦略 / D魔獣の獲得・進化欲 / E再戦意欲。各0～5点。初回H1平均4未満はFUN_NO_GO、H0比較で改善の理由・最悪不具合・画面録画（ユーザー任意）を残す。これは企画室の比較基準であり、実際の検収済みではない。
