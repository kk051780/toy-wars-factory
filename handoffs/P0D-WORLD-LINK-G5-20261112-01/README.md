# TRAP RAIDERS｜G5 陸・海・空をつなぐ子供向け3Dフィールド

Issue #224 / WORLD-FIELD-ENGINE #222 / source-only S2+.
Owner slice: `WORLD-LINK-G5-3D-20261112-01`.

## 実際に用意したもの
- 3段階の地形：草原・青い港・海底ガラス城・空中の浮遊城。海底は**水泳シミュレーションではない透明な乾いた通路**であり、泳げるとは宣伝しない。
- 港の青い橋、海底への泡の坂、別の緑の秘密坂、空の黄色の坂、紫の坂。全ルート無料で両陣営利用可。
- 単独Luauの`WorldLinkRoutes.luau`は世界の全経路・簡単操作・守備側の対応を原本として記録し、歩いて往復できるルートグラフの静的検証を実装。
- `WorldLinkScene.luau`はオリジナルのPart/Glass/Cloud/看板/2つの城/港/中立SpawnLocationを組み立てるRoblox Studio用実ソース。
- `WorldLinkDemo.server.luau`は**初期値 false**。既存 `TRAP_RAIDERS_S1` があれば起動拒否。公開/報酬/戦闘/卵/課金/外部アセット無し。
- 各ルートに個別7秒・15秒広告原稿と職業/アイテム連携の仮説、子供に見える合図、敵の対抗策、H0/H1、失敗回復を書いた機械可読JSON。

## 注意と手順
- **未検証**：実際のRobloxキャラが坂道を登れるか、落ちないか、スマホ60FPS、海底の景色が本当に美しいかはStudioで未確認。ここで製作したのはオリジナルの3D生成**ソース**であり、実機合格ではない。
- 透明な水色のボリュームは乾いた見た目用。Terrainを変えないので既存の別Placeへの副作用がない。将来、水泳を導入する場合は泳ぐ理由と落下復帰に専用検証が必要。
- デモを使う際はOWNERの最終バッチ許可後、非公開でバックアップ済の新規PlaceにRojoの`default.project.json`で読み込む。試験時のみ`ENABLE_WORLD_G5_DEMO=true`を隔離コピーで設定。
- `#220`の公式S1 releaseに直接改変/merge/公開する作業は認めない。S1最優先、Studioの発見事項は隔離レーンで修正する。

## 可視化と戦術
- 陸：宝を集める本拠・安全な選択肢。今回は卵/宝の実アクションは無い。
- 海：青い正面橋 or 緑の迂回通路。正面の守りを誘い、友達が裏を通る。
- 空：黄色の表斜路 or 紫の裏斜路。攻城と待ち伏せの選択が増える。
- 珍しい中立キャラの名前は別のD18/ボス図鑑にある企画だけで、本パックでは**現れない**。
- 広さだけのための移動時間は不採用。見つける楽しさと戻れるルートを優先。
