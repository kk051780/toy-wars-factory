# P0D企画室・新しい遊びの原型：星のジャンプ台

**ID** `P0D-STUDIO-ACTION-STAR-JUMP-001` | 独立企画 #267 | 日付 2026-11-13 JST

**製品段階:** S2候補・OPTIONAL private Studio prototype. この新機能は **公式RC/初回リリースに未採用**。現在の H1 試遊の面白さ判定を先送りさせる理由にはしない。

## 実ゲームで何が起きるか

既存の28スクリプト H1（本物の卵強奪→運搬→納品、RAIDER風走り/ GUARDIAN罠、海と空の近道、動く2体の幻想生物、子ども向け運搬ボタン表示、案内ドラゴン）の**ソースを28/28そのままに**、サーバーScriptと純粋ルールModuleScriptを各1本追加する。

海への出入口に近い赤城側 `(-66,1,-20)` と青城側 `(66,1,-20)` に、色が違う「⭐星のジャンプ台」を各1つ置く。タップまたはEキーを押すと、勢いよく**中央方向へ斜めに飛ぶ**。両チームともどちらの台も使えるため、卵を抱えて逃げる側にも追う側にも選択肢ができる。台の方向・飛ぶ速度はサーバー定数で、プレイヤーは変更不可。

- 横方向62 / 上72 / 斜めZ+16 stud/s、クールダウン12秒。空中再連打禁止、死亡時・非所属時・遠隔操作禁止。
- ダッシュ・攻撃・卵/勝敗/HP・D18コレクション等の既存の権威に干渉しない。報酬・ガチャ・課金・新Remoteは**ゼロ**。
- 既存アリーナ範囲 X±125/Z±71 内に台を配置。ジャンプの実軌道・着地・衝突はStudioで要検証。2つの元のマップと障害物を変更しない。
- `RunService:IsStudio()` の強制ガードで公開プレイ時には不作動。QAまで行っても公開可能とは言わない。LIVE enable/リリース審査は#264および#220の別担当。
- 子どもが1タップで気づく「動く・選ぶ・追いかける」価値を試し、単なる背景追加を避ける。

## 反証可能な「勝ち筋」実験

**仮説：** H1に星ジャンプを足すと、初見児童に「海の逃げ道からジャンプして逃げるか／相手に使われる前に追うか」という分かりやすい判断が生まれ、H1コントロールより再戦意思と試合中の自発的行動が増える（**実測前で不明**）。

- **対照A:** 元の #262 28-script H1 FAST ROUTES + 子ども向けHUD、ジャンプ台なし。
- **実験B:** Aの28-script完全保持 + 新しいサーバー物理ジャンプとポリシー2-script。
- **実機チェック:** 2クライアントで双方がジャンプする/敵も台使用可、卵を持っても本来の納品ルールが維持される、地上からしか起動できない、悪用できない、近道がかえって逆転を不公平にしない、スマホでタップ対象が見える、画面外・場外へ飛ばない。
- **楽しさ評価:** 15秒で目に付くか、30秒で意味が分かるか、90秒以内に1回使いたくなるか、H1単体より「もう一回」が増えるか。1–5段階/言葉で記録。ユーザー数・再戦率・定着・課金率 **すべて UNKNOWN**。
- **停止条件:** 空へ突き抜ける、場外・城壁・海の衝突、本人が降りられない、一方陣営が不利、強制利用に見える、酔い/眩しさ、端末負荷、初回卵取りの邪魔になる。
