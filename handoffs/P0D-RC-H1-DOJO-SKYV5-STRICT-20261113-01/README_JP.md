## 今回の独立統合内容
直前に統合が成功した45スクリプト版（B42卵1/5・V7無双戦闘・進化/育成・天空城・Studioソロ開始・道場2系統）を元に、次の作者納品物を実際のPlaceへ取り込みました。

1. **天空城の登り口／降り口を各陣営2か所ずつ、合計4本追加**。既存の空中経路と地面の間にある約1.9スタッドの段差を低勾配でつなぎます。ジャンプ必須にならないことを目指す、子ども向けの物理的な近道です。移動速度の課金やワープはありません。
2. **画面右下0/4→4/4の卵運搬監査を厳密化**。旧版では天空城で卵を持った後、途中で卵を落とす・他者が得点するなどしても4/4の誤成功があり得ました。今回の診断はサーバーが直前まで報告した卵IDが一致し、キャラクター／ラウンドが継続し、直下へのレイキャストが本物の島の床を検出して接地、1人サーバーで同じ卵の解放と同時に本人チームの得点増加が観測された場合だけ最終段階へ進みます。持ち替え・落下・死亡・ラウンド終了で`ROUTE_RESET`、関係ない得点は`SCORE_NOT_QUALIFIED`として扱います。

ゲームの唯一の`Game.server.luau`、卵得点処理、HUD、V7無双戦闘、BEAST/WEAPONの放置道場・友達XP・保存処理・1人練習開始条件は**今回いっさい変更していません**。元の45スクリプト中43本がバイト単位で完全一致、置換対象は作者の天空城ワールドとStudio観察LocalScriptの2本だけです。合計45本、ゲームのRemoteは既存の1個です。

## Studio試遊
1. GitHub Actions最新成功版のZIP内`EGG_RAID_RUMBLE_H1_DOJO_SKYV5_STRICT4_PRIVATE.rbxlx`をWindows版Studioで開きます。**公開・マージ・課金はしないでください**。
2. Studio `Test→Play` で1人で開始。自陣の「魔獣道場」「武器道場」に立って、セッション経験値・Lv表示が増えるかを確認します。
3. 敵陣の卵を取得し、**新しい低勾配の入口から徒歩で天空城へ登り、出口から地面へ戻って納品**してください。踏み切りジャンプ、段差による引っかかり、滑落、卵が途中で消えるかを確認します。
4. 右下の試遊検証表示が0/4→4/4となるか、Output `[P0D_STUDIO_FUN_CHECK]` の`EGG_CARRIED`、`SKY_WITH_EGG`、`SCORE_AFTER_SKY`を確認します。もし失敗したら`BLOCKED`、`ROUTE_RESET`、`SCORE_NOT_QUALIFIED`も確認して記録します。
5. **負例試遊**：天空城で卵を持った後に落としたり、死亡・リスポーンしたりしてみてください。その後ほかの得点で4/4にならないことを確認します。
6. Studio 2人対戦でも元のルールが維持されているかを確認し、片方が退出した場合は練習モードにすり替わらず通常の終了判定が行われるかを確認します。
