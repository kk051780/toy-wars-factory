## 見た目の制作ルール
- オリジナル低ポリシルエットを3つの大きな特徴で定義する。遠距離LODでも3特徴を残す。
- 子どもが色に頼らず輪郭で区別できることを優先。高レア感は形と演出で表現し、購入優遇なし。
- 次の本実装タスクでのみ**近景24/遠景16 Part以下**を目安にWorldModel専用Luau 3Dを作る。現在の6体は「デザインのみ」で、3Dモデル完成数に加算しない。
- 魔獣・魔法・乗り物・武器・ゾンビ・罠の各1種類を維持。ゲーム内能力は必ず攻撃側と防御側の両方に意味を持たせる。
