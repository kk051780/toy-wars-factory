These generic helper scripts are included to verify ZIP manifest/SHA and to understand the P0D_AES256_GCM_HANDOFF_V1 envelope.
Prefer the reviewed safe restore utility at immutable GitHub commit d37eec1b653d060ae27568ddcd5f501da9662081 (tools/restore_handoff_safe.py) for actual owner Windows Codex restoration.
Do not use shared mutable paths, echo AES keys, or run ZIP scripts without source review.
