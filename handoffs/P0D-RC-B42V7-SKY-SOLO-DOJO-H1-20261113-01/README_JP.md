# P0D 統合担当｜B42＋V7＋天空城＋ソロ試遊＋診断＋放置道場 H1（非公開）

## 今回、実際にゲーム内容を増やした点
元のB42には「卵の奪い合い」「戦闘」「90秒ナビ」「進化」「5卵モード」「V7の雑魚戦」「天空城」があります。既存の「試合開始時に固定したStudio1人練習」と「天空城を経由した卵運搬の4段階試遊診断」に加え、企画室の **魔獣・武器の自動修行道場（計4台、赤青対称）** を実際のサーバーGameに接続しました。

ソースは統合担当の隔離ブランチのみに書き込みます。作者の元ファイルに差し戻しや上書きをかけません。既存ゲーム44本のうち42本は完全に同一、元のGame/HUDの2本のみ、作者の実装済みパッチを利用して変更。作者の純粋Luau DojoRulesを1本追加し、合計45本。Gameplay Gameは1つ、Remoteは元の1つだけです。

## 試遊時にできること
1. Windows Roblox Studioで配布ZIPの `.rbxlx` を開きます。**公開しないでください。**
2. `Test → Play` を1人で開始。マップREDまたはBLUEの自陣近くにある `🐉まじゅう道場` または `⚔ぶき道場` に乗るだけで修行が進みます。ミニゲーム操作は不要です。
3. 道場のHUDにレベルと経験値が表示され、各レベルは最大Lv5。実際にフレンドが同じStudioサーバーにいる場合は、サーバー側のフレンド確認成功時に経験値1.5倍。魔獣／武器ともレベルに応じて**雑魚敵・召喚した魔獣の対NPCダメージのみ**最大+20%。PvPの攻撃力・体力は上げません。
4. そのまま敵の卵を奪って逃げ、自陣へ納品します。試遊用の右下診断は「試合開始→卵取得→卵を持って天空城の床へ到達→サーバー得点増加」の0/4〜4/4を表示します。Outputにも `[P0D_STUDIO_FUN_CHECK]` が出ます。
5. 2人用Studioサーバー試遊では、2人で試合開始後に片方が退出しても、勝手に1人練習へ切り替わらず通常の勝敗判定になるか確認します。

## 機能の限界／未実装
- **今回の道場はBEAST/WEAPONの2スキルだけ**。ユーザー構想の6分野すべて／ランダム10分切替／自由選択30分／課金による優先選択はまだ含めていません。
- 育成経験値は**セッション内のみ**。一度退出すると失われます（保存実装は別担当で実験中）。既存の卵や本来の進化のデータ保存まで変更・保証するものではありません。
- フレンド確認はサーバー側で行い、新規加入時の認証が中心です。同サーバー接続でも認証状況によりボーナス表示の有無が変わる可能性があります。
- 画面右下の4/4は**ローカル接地＋サーバースナップショットの組み合わせ**による試遊観測値であり、完全なチート耐性・移動経路証明ではありません。
- native LuauテストとRojo Place生成がPASSしても、Studioエンジン上での1人/2人のリアルな試遊、Android操作、継続率、面白さは**NOT_TESTED**。実測結果がないまま「リリース可能」と判定しません。
