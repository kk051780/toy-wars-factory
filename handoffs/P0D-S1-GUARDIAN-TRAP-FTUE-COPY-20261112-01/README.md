## 今回の欠落と修正

正式RC `1263a03701211a652b99b91d2339575dc8104eff` には守護役の罠が実装されています。右下の「罠設置」ボタン・Tキー、20秒の設置間隔、敵の速度を一時的に落とす効果があります。ところが既存の `FirstMinuteModel.luau` には「罠」の遊び方が一度も登場せず、最初の12秒は攻撃だけを説明していました。

今回の `candidate/src/shared/FirstMinuteModel.luau` は**元ソースの4箇所だけ**を変更。子ども向けの日本語として次の内容を加えました。

| タイミング | 変更点 |
|---|---|
| ロビー | 「守護は体力が多く、罠を置ける！」と役職の違いを説明 |
| 対戦開始〜12秒 | 「自分の卵を守ろう」「右下の罠ボタンで足止め」 |
| 12〜32秒 | 守護だけ「自分の陣地でTキーか右下の罠ボタン」 |
| 32〜60秒 | 守護だけ「20秒で次の罠」「敵の卵も奪える」 |

**変更しない要素:** サーバーの罠設置条件・ダメージ・リモート・マップ・ゲームループ、ロール判定、モデルの状態遷移、スナップショットの検証、60秒での自動非表示、手動ヘルプ、卵を持った時・得点時・結果表示の優先順位、速攻役の既存チュートリアル。

`FirstMinuteModel.luau` の元Git Blobは `fcdc399bf95b6cd0532691718f5a54e8a4fd84b4`。元の`S1TrapRules`、`Game.server`、`HUD.client`も正式RCの固定Git Blobを厳密照合して、20秒・速度低下・実際の罠ボタン実装の根拠を確認します。
