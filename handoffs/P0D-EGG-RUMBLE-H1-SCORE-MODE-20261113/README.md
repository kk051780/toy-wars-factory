# EGG RAID RUMBLE｜既存H1ゲームに5個卵得点制を組み込んだ本物のA/B試遊候補
2026-11-13 JST／Issue #277／internal game_id TRAP_RAIDERS、work_id p0d-siege-v19

## 市場・企画の融合
Steal An Egg系の『卵を取る／集める』という直感的な目的を、オリジナルの城塞PvPvE・海空の三経路・RAIDER風走り・GUARDIAN罠に融合する。城へ納めるか、抱えたまま逃げるか、自軍の卵を守るかを子どもが選べるようにする。先行ゲームの絵・UI・キャラ・名前の模倣は行わない。
2026公式デザイン参考： https://create.roblox.com/docs/production/analytics/retention と https://create.roblox.com/docs/production/game-design/core-loops 。人気を確認しただけで売上・定着率の上昇は証明されていない。

## 実際のゲームソースで何をしたか
- 元の完全H1ゲーム#270 30本、固定コミット 1f63a529dc512487145cea86557d38cec7f19e03 を再組立。現在の本物のGame・MapBuilder・2職・サーバーRemote・ガード罠・風走り・海と空の近道・2匹の移動する幻想生物・案内ドラゴン・卵獲得演出を使用。
- スコア源は独立#272で実ネイティブ1212条件合格済のオリジナルH2 MultiEggRules（Git blob 0999d69391c176b9b95b04c5444d822e63d7ce04）を一文字も変えず再利用。
- 実際のGame.server.luauを、この独立ブランチ内のコピーだけ修正。既存2つの城の卵をR1/B1として再利用、赤R2／青B2／中央N1の3個を物理Part・ProximityPromptとして追加。元の1つのGameサーバーで取得→保持→DROP→納入→定期得点→4分決着を扱い、新しいGameや得点Remoteを作らない。
- その他の元のH1ゲーム29本を完全にバイト保持し、上記得点ポリシー1本を追加。実ゲーム合計31 Luau。
- builderはA＝旧1卵勝敗ルール（得点制OFF）、B＝Studio限定5個卵4分得点制ONという２つの完全H1試遊版を生成。通常公開の環境ではBでも得点制OFFになる安全ゲート。両者とも正式公開してはいけない。
- 卵の取得と納入は元のサーバーの生存／チーム／距離検証、試合状態、元のPromptだけを使う。RAIDERは卵運搬中に風走り不能、GUARDIANの罠も既存規則を維持する。死亡・切断・範囲外ではDROPをする。

## 5卵の試験用得点（元#272と同じ）
| 行動 | 得点 |
|---|---:|
| 敵卵・中央卵を保持 | 10秒に+1 |
| 自軍卵を持って防衛 | 30秒に+1 |
| 自軍卵を自陣に置く | 20秒に+1 |
| 敵卵を初めて自軍金庫へ納める | +12、その卵とチームは試合中1回 |
| 敵卵を自軍金庫に保管 | 10秒に+3 |
| 中央卵を初めて自軍金庫へ納める | +10、その卵とチームは試合中1回 |
| 中央卵を自軍金庫へ保管 | 10秒に+2 |
| 敵に奪われた自軍卵を回収・納品 | +2、卵あたり試合中1回 |

試合時間240秒、同点はDRAW。別スコア原案#273にある30秒延長試合は未実装。子どもが理解できるか、所持より金庫が強過ぎないか等は未検証。

- この統合版では新しい5個卵すべての位置や保管状態を端末に分かりやすく説明する専用UXは未実装。既存D18ドラゴンの案内は元の敵卵1箇所と自陣納入先の表示を流用する。
- ユーザーの最新必須要件#275：試合後の無料レア卵孵化→OWNEDと図鑑→事前装備→次戦で本当に魔獣/魔法/乗り物/武器/ゾンビ/罠として使えること、永続保存・重複対策は今回のH2得点実装には **まだ含まれない**。あくまで次の実ゲーム縦切り課題。
