## 独自の勝ち筋

「1個盗んだら勝ち」から「4分間で得点を競う」に変更する任意の将来ルール案。赤・青の城に2個ずつ、中央に中立1個の計5卵を置く。1人1個しか持てない。サーバーが定時得点と合法的な持ち帰り得点を計算する。

| 状態 | サーバー得点 |
| --- | --- |
| 敵の卵を持って逃げる | +1 / 10秒 |
| 自分の卵を持って逃げる | +1 / 30秒 |
| 中立卵を運搬する | +1 / 10秒 |
| 自分の卵を自陣金庫に保管 | +1 / 20秒 |
| 奪った敵卵を自陣金庫に保管 | +3 / 10秒 |
| 中立卵を自陣金庫に保管 | +2 / 10秒 |
| 敵卵を自陣に初めて合法納入 | +12 / 卵・陣営・1試合1回 |
| 中立卵を自陣に初めて合法納入 | +10 / 卵・陣営・1試合1回 |
| 実際に敵に支配された自陣卵を取り返す | +2 / 卵・1試合1回 |

デザイン原本の「真正capture-cycleごとの納入加点」に対し、この原型では不正な同一卵の往復で稼げないよう、**同じ卵と陣営の納入ボーナスは1試合1回**と明確化した。実機QA後に「正当に再奪取した場合だけ再加点」に調整可能。これは原作者のゲーム設計採否を勝手に更新したことを意味しない。

## ルール実行の契約

- 元のS1 Game.server.luau / MapBuilder / HUD は**一切編集しない**。本コードは純粋な \`MultiEggScoreRules.luau\` テーブル関数だけで、Robloxの RemoteEvent / workspace / 球体の複製、データ保存、課金機構を作らない。
- 5個の卵は \`RED_1/RED_2/BLUE_1/BLUE_2/CENTRE_1\`。各卵の state は \`NEST\`, \`VAULT\`, \`CARRIED\`, \`DROPPED\` のどれか一つで、\`holder\` は1人のみ。死亡・離脱では持ち物を \`DROPPED\` にする。実物理座標・地面への安全ドロップは**今後のStudio実装で別途**必要。
- \`addPlayer(state,id,team,epoch)\`、\`event(state,epoch,id,seq,action,eggId,trustedNear)\`、\`advance(state,epoch,seconds)\` など、既存唯一のサーバーGameが将来呼ぶ前提の API。ここに入れる \`id/team/trustedNear/epoch/seconds\` は**クライアント入力ではなくサーバーが検証済みの値だけ**。純関数側の距離フラグ単独では遠隔詐称を防げないため、統合時は必ず Roblox の実位置/距離/LOS/床/城金庫判定をサーバーで行う。
- 正規のイベントであっても seq は単調増加の整数でないと受け取らない。失敗した有効seqも消費するため後から条件が成立しての「古い入力が成功する」を防ぐ。古い round epoch は拒否。終了後イベント/点数加算拒否。
- 運搬時間の累積は1卵・現在の保持状態ごとで、pickup/drop/vault transfer時に秒数残りをリセット。卵を高速で出し入れして加点を加速させない。得点は整数・サーバーの時計でのみ。
- 240秒時点で勝ち越しなら勝利。同点は30秒延長。中央卵は一度元の \`NEST\` に戻して、新しく確保して自陣納入した方が勝利。それ以外の期間得点は延長中停止。270秒終了で同点なら \`DRAW\`。既存のユーザー提案の「新規中央卵」から、単純で競り合いの分かりやすい延長仕様にした。
- 当面3職追加やガチャ/図鑑ではなく、**持ち逃げ・自陣卵の護衛・追跡・中央争奪**の基本的な判断価値の検証を優先。キャラ案は後から、現場の反応を見て追加する。
