## なぜ強さを上げるか

ゲームを繰り返すことで、目に見えて敵を圧倒し新しい攻撃・演出・召喚が増える**パワーファンタジー**を提供したい。かつて苦戦した普通のゾンビをLv50ではまとめて倒し、Lv30以上で伝説の幻獣や巨大ボスに立ち向かう動機を作る。一方、チームの卵争奪戦で育成済みの1人が毎回無条件勝利すると初心者・復帰ユーザーが辞めるので、**PvEの大幅強化とPvPの上限あり強化を区別**して実験する。

**数値を売りにするのではなく、実際の魔獣進化/魔法/戦闘モーションが重要。** `Power.ultimate` が返す現在の名前は将来実物を作る契約案（Lv10覚醒の一撃 / Lv30幻獣の共鳴 / Lv50天龍降臨）で、今は**実際の奥義アニメーション/当たり判定/3Dドラゴンは存在しない**。`damageMultiplier=1`は追加の隠しバフがないという意味。

## 8秒の覚醒「無双体験」

- Lv10で覚醒可能、1試合1回のみに制限。
- サーバーが事実と認めた**卵の納入＋45、奪還＋35、護衛＋20、防衛＋20、取得＋10**で80以上の覚醒値を獲得。
- 同じ卵を出し入れして貯め続けることを防ぐため、イベントID重複拒否と各アクション種別に上限。`KILL`やAFK、クライアント自己申告ではチャージしない。
- 卵を持っている間は発動不可（敵チームの獲得権利が消滅しないようにする）。離すか城に運んでから使う。
- 発動時に **2秒の見える予兆**があり、8秒間だけ強力な能力・攻撃補正。敵は遮蔽物、距離、罠で対応可能とする。**見える演出・実際の対抗手段はまだ実装していない**。このサーバールールだけを取り付けて公表するのは禁止。
- Lv1-9でも無料スターター能力・護衛・防衛・卵搬送が行える。初心者向け短いチュートリアルとLv10の覚醒目標を用意する。強者と同じ敵しか出ないと初心者が即離脱するため、必要に応じてスキル/育成のマッチングを検討。ただし最初は人口不足の分断を避ける。

## 今後の本当に使える魔獣・魔法の成長との結合

#281の`profile.level`、#275/#280の`owned/equipped`、#281の`mastery.level`を**既存Gameのサーバー内だけ**で照合。PVPの補正はサーバーの正規ダメージ処理の対象別枝にのみ入れる。NPC撃破や攻撃はPvE枝、他PlayerへはPvP枝で分離。倒して経験値を無制限に稼ぐ仕組みを追加しない。全職業の実能力・上位魔獣・騎乗/大型魔法を1つずつ実装し、3D見た目・スマホ操作・相手の対抗手段も検証してから段階的に拡張。

課金による`XP`、`attack boost`、`awakening boost`、`legendary power`の販売は禁止のまま。すべての戦闘能力は無料のプレイで獲得可能。課金は販売内容が確定したコスメティックを基本とし、金銭による勝率格差を作らない。

## 安全・性能・ゲームバランスの実証ゲート

- レベル1、10、30、50を対等なレベル帯・異レベル帯で**実際の対人戦**に参加させ、被撃破までの時間・勝率・1回の無双技の反撃成功率を調べる。

- 低Lvが高Lvに勝つルート（戦術、護衛、罠、防衛、移動）を保ち、卵の運搬に覚醒を重ねて確定得点になる抜け道を防止。
- 公開・課金・大規模レベルマッチング変更はユーザーの別承認必須。
- マッチメイキング基礎: https://create.roblox.com/docs/matchmaking ; コアループ: https://create.roblox.com/docs/production/game-design/core-loops
- すべて**バランス仮説**。実利用者データや実機の楽しさはまだ不明。
