# EGG RAID RUMBLE｜同じゲームで「卵どろぼう戦」と「卵5こ得点戦」を選ぶ
企画・実装：2026-11-13 JST｜#279｜内部ゲームID TRAP_RAIDERS / p0d-siege-v19

## 画面と遊び方
プレイヤーは同じゲームに入る。ロビー／開始カウントダウン中、画面中央に子ども向けの大きな２ボタン。

- 🥚 **卵どろぼう戦（CLASSIC）**：今まで通り敵城の卵1個を奪い、自陣の台へ戻す。城破壊でも決着し得る元の攻城ルール。ゲーム中のRAIDER風走りとGUARDIAN罠は共通。
- 🏆 **卵5こ得点バトル（SCORE_5）**：赤2個、青2個、中央レア1個、4分。自分の卵を守る、敵卵を奪う、持って逃げる、城の金庫へ納めると点がたまる。1人1個所持。終わった時点で点数が高いチーム勝利。

**選択仕様**：同じ対戦に参加するRED/BLUE全員が投票。多数決で次戦のモードを選ぶ。未投票・同数なら慣れたCLASSIC。投票変更は開始前なら可（0.4秒以上の間隔）。試合開始時にサーバーが確定し、試合中の変更は受け付けない。結果発表後、全員の投票をリセットして次戦は再び選べる。退室した人の投票は消す。人数の少ないマッチでも同じ規則。

## 本物の既存H1を共通化
既存#277の実ゲーム31 Luau（#270 のH1短縮海空・城・2職・戦闘・風/罠・案内ドラゴン・幻獣・初卵演出、#272の実Luau卵5個ルール）を継承。ソース差分は **既存のGame.server.luauと既存HUD.client.luauの2本のみ**、さらに**純粋なサーバー投票判定 ModuleScript を1本追加**した計32本。ほかの29本のゲームLuauはバイトそのまま。元の実ゲーム Remoteは1つ、Game管理者も1つ。二つの別ゲーム/Placeを行き来する必要はない。

HUDは元の唯一のseqとRemoteを使い、MODE_VOTEの入力は既存プレイヤー権限・単調seq・Phase・Studio・投票間隔・mode許可リストを検査して受理。Clientは勝敗、score、Playerの位置、mode切替時刻を選べない。投票集計はサーバーの現在のプレイヤーリストのみを数える。順位や人数の不一致／同数はClassicへフェイルセーフ。

**実験用安全制限**：本ゲームのSCORE_5は現時点でStudioのみ有効。非Studioの同一Placeで得点戦を勝手に有効化できない。正式公開前には、#220 唯一のRC担当とOWNERが#264に相当する将来の安全なゲームID/Place ID・モード認可を再設計し、原本をコピーして完全な検査をやり直す。ここでの機能ONと公開許可は別。
