## 何ができるゲームになるか

本物のH1卵争奪ゲーム #262 の **28本のLuauを改変せず**、中立魔獣「まもりの門獣」を1体、中央通路のそばに実装した。

- **目覚める：** どちらのチームでも中央通路に近づくと、サーバーが魔獣の反応を計算
- **知らせる：** 黄色の予告線と「うみ・そらへ まわれるよ」の看板を2秒表示
- **通せんぼ：** 通路に人がいない場合だけ本物の物理障害物 `CanCollide=true` を5秒発動
- **解除：** 解除後8秒は再発動なし。予告中に人が通路に残った場合、5秒で発動を諦めてクールダウン。急に人を壁に埋めない
- **意味：** 真ん中を直進する・海へ逃げる・天空から迂回するという戦術の選択が生まれる。どちらの陣営も同条件。壁は中央だけで海・空には配置しない
- **造形：** 球形の真珠色ボディ、丸い角、光る2つの目、柔らかい頭の動き。オリジナル少数Part。目色が緑→黄色→赤に変化し、子どもが状態を理解できる

**ゲーム内での真の変化**は一時的な衝突判定であり、看板・絵だけではない。風ダッシュ・罠・卵・城HP・得点・再試合・動く元の幻獣2体・D18案内ドラゴンには触らない。RAIDER/GUARDIANの2職のみ。

## 根拠・仮説・反証

- **一次資料** Roblox [Onboarding](https://create.roblox.com/docs/production/game-design/onboarding)：初回プレイの理解と離脱を重視。こちらの推定は「魔獣の予告→2秒後に経路を選ぶ行動が理解できるか」。
- **一次資料** Roblox [Parts](https://create.roblox.com/docs/parts)：AnchoredとCanCollideで物理通行可能性が変わる。ソース上はアンカー済ゲートのサーバー切替え。実際の足元・衝突・カメラ挙動は**Studio未検証**。
- **一次資料** Roblox [Securing client-server boundary](https://create.roblox.com/docs/scripting/security/client-server-boundary)：悪用可能なクライアント操作に権威を与えない。魔獣はクライアントRemoteやクリックを要求せず、サーバーのプレイヤー位置/Team/Humanoidと単調時計のみ参照。
- **独自性** 市場にある卵コレクション作品の魔獣造形、キャラ名、アート、音源を模倣しない。既存のTRAP RAIDERS攻城/罠/天空/海をつなぐ「中立の通せんぼ」という自分たちの文脈を強化する。
- **実測前の反証可能仮説**：元H1（対照A）より、初見15〜90秒間の自主的な海/空迂回選択や再戦意向が増えるか。予告が難しい、壁に挟まる、追う側だけ不利、2回以上通路が封鎖されストレス、低FPSなら棄却。現実のユーザーテスト・D1継続率・収益は **UNKNOWN**。
