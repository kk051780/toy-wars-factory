## 0. OWNER確定仕様：1試合限りの成長と、試合内の「無双」を魅せる（2026-11-23）

> **最優先の明示方針：** 「もちろん戦闘が終わったら元に戻るシステム。その戦闘の中での活躍度と、無双度合いを魅せられるシステムにする」。本項は以下の初期仮説と衝突する場合に優先。**戦闘＝開始/終了が明確な1試合（match_epoch）**であり、個々の敵との交戦終了ではない。

- **開幕：** 新規match_epoch開始時に、全参加者の **試合専用** BattleLv=1 / BattleXP=0 / neutralKO=0 / playerKO=0 / assists=0 / streak=0 / peakStreak=0 / eggDeposits=0 / defenseContribution=0 / 見た目の成長段階=初期値。既存のベース役職・本来の能力を勝手に変更しない。
- **試合中：** 中立兵や敵対プレイヤーのサーバ確定KO、卵の納入、城防衛、味方支援等によって BattleXPが上がり、役職の一時能力と外観、頭上の活躍表示が成長する。試合内だけの連続撃破・戦功は途中で見ることができる。
- **KOと死亡：** 死亡時は原則、当該matchの BattleLv / XP / 累計KO / 貢献を保持し、連続撃破streakだけ0へ戻す。死亡ペナルティと取り戻し可能性のバランスは2clientで検査。試合間の持越しは不可。
- **試合終了：** 勝敗確定・ラウンド切替時、前試合の一時ステータス/能力倍率/巨大化・装飾/バトルLv/経験値/連続KO/頭上の覇者表示は**全員0クリアし、初期姿と既存のベース能力へ戻る**。結果画面のみ、その終了済み試合の確定結果を一時表示できる。次試合に前回の加算や結果タイトルが混じらない。
- **途中退出と再入室：** ユーザー別セッション/round_epochを照合して旧試合からのLv・KO・装飾・非同期イベントを新試合へ引き継がない。新しく参加した試合はLv1から。画面の古いBillboard/FXも確実に破棄。
- **データ保存：** 一時戦功・成長・キルストリーク・試合限定称号を DataStore に保存しない。既存の永久育成/解放・実績がある場合でも、今回の「無双」強さと巨大化を永続化しない。旧案の熟練による初期BattleLv+1（H4）は **DEFER**。現時点のH1では全員一律Lv1開始。別の明確なOWNER決定なしに永久強化へ変更しない。
- **表示原則：** 頭上・HUD・ランキングには「**この試合**」と明示し、累計プレイヤー対人KOと中立NPC KOを必ず別々に表示。外見だけで偽の撃破数を暗示しない。卵奪取・守備・回復も称号で称え、単純なKO独占にしない。

## 3. 二重成長構造：恒久熟練と試合内バトルLv

**A. 恒久熟練（アカウント別・役職別）**
- 前回までの既存保存武器Lv/役職熟練に相当する「長期継続の証」を活用する。既存Storeに役職別永続値が存在するかをソース・profile・実機で確認し、未確認なら**新しい保存スキーマを勝手に増やさない**。
- 既存の恒久熟練があるなら、その表示は肩の紋章・プロフィール等に限定し、今回の**試合専用バトルLvや無双バフとは独立**させる。開始時のLv+1案は今回のOWNER「戦闘終了で元に戻る」方針のもと **DEFER**。全員Lv1開始、試合ごとに同じ条件に戻ることをMVPの原則とする。**強者の永久無双・課金強化は不可**。
- 恒久熟練Lvと試合中バトルLvをHUD・保存・結果画面で混同しない。

**B. バトルLv（毎試合Lv1〜Lv5）**
- 全参加者が同じ役職基本能力と最小Lv1から始めるH1を先に検証。役職を選んだ後、サーバで確認された中立兵撃破・対人KO・卵納入・防衛貢献からバトルXPを与える。
- **各撃破で経験ゲージは必ず増え、最初の中立兵撃破でLv2に到達する仮説**。毎KOでLv自体を無制限に加算せず、段階閾値で上限を設ける。
- **試合終了で BattleLv/XP/中立KO/対人KO/連続KO/貢献/称号/巨大化/一時スキル倍率をすべてリセットして元の姿に戻す**（詳細は最優先「OWNER確定仕様 §0」）。恒久熟練は既存の正式サーバ保存経路のみだが、今回の試合専用能力とは結合しない。
- 死亡で累計バトルLvをゼロに戻すと初心者が離脱しやすいのでH1ではバトルLvを保持し、連続撃破称号のみリセット。劣勢逆転策は「低Lvの防衛/卵行動に追加XP」案を実測後に選別。
