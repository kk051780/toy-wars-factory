# QA evidence standard

**Grade 0**: concept proposed. **Grade 1**: code saved. **Grade 2**: deterministic host/offline tests with logs. **Grade 3**: Roblox engine execution with logs. **Grade 4**: real cross-client/mobile screenshots, representative user tests and performance. Only Grade 4 may be considered for release; still requires owner approval.

Each cycle reports code path, commit SHA, changed bytes, tests PASS/FAIL, known defects, gameplay impact, character audit and engine limitations. Size reductions are permitted with a recorded reason; silent deletions are not. Failed tests require a defect/cause/regression entry. No agent can lower quality gates by modifying this file without owner approval.

The 20-minute cron is best-effort, may be delayed, and is not continuous execution. Workflows have job timeouts and usage/billing limits.
