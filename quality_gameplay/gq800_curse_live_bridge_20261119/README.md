# GQ800 — single Swarm live curse conversion bridge (2026-11-19)

This is **new and not duplicating** #801's PURE curse policy or #815's eight-type neutral/finisher implementation. The omitted integration is real neutral ownership and behavior when confirmed neutral hits occur. It composes immutable #815 **43-source actual Rojo source packet** plus exact #801 CurseConversionPolicy Git blob `0bd81a807ff6a935642a660b9fe9e0fd05ef484c` into a **44-source private candidate**, with **the original singleton Swarm patched in place** (no second spawner, second HP authority, Store, Remote, gameplay server, or reward processor).

Runtime scope: original authenticated server neutral damage issues seal receipts; only server-role ZOMBIE, current owner castle and living avatar, visible real living neutral within 32 studs may seal; two genuine distinct hits within five seconds and target at <=35% HP permit an up-to-14-second conversion. Converted neutral gets an in-world green accent, follows its owner's actual character, ignores players/castles, strikes at most one other unconverted neutral every 1.3 seconds inside seven studs with a line-of-sight check, and credits only via original Swarm death logic. On death/expiry/role swap/match end/owner death it reverts, and converted friendlies cannot be attacked by the same original player splash loop. No new UI/Remote/order command; only server-set **FOLLOW** is currently real. GUARD/FOCUS user selection remains unimplemented. Enemy attacks may kill a neutral before a second qualifying seal; conversion probability and fun need actual Studio balancing. **Not a complete seven-role acceptance.**

Conservative combined summons cap: policy supports up to three charmed, but because old ZOMBIE can already summon three independent units and there is no verified trusted unified count, bridge passes three for `existingSummoned`, permitting at most **one** charmed neutral at once per owner; this strictly avoids exceeding total four summons. Lift only after a single trusted summon-count owner is identified and native-tested.

CI consumes the already-successful genuine source packet from #815 run [44319832599](https://github.com/kk051780/toy-wars-factory/actions/runs/44319832599), original #801 source blob, then tests **all 43 OFF and 44 ON Lua** with pinned Luau native compiler and Rojo 7.7.1, byte-exact original OFF43 rollback, 42/43 old sources unchanged and no new remote/Store authority. No official RC, Roblox publish, paid action, PC interaction or Studio/Android human playtest. The official target is only `rc/p0d-s1-kids-rc01` through verified #220 B nonforce expected-SHA CAS, after new source selection and independent review. This small branch is an integration intake candidate; not a second canonical RC.
